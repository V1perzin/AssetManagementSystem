# Asset Management System

Mockup visual responsivo para o Sistema de Patrimônio.

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador. Não é necessário instalar dependências ou configurar um servidor.

## O que foi incluído

- Menu lateral responsivo com navegação por seções.
- Dashboard com indicadores, resumo e atividade recente.
- Formulário moderno de cadastro.
- Lista de patrimônios com busca, filtro por estado e ações.
- Tela de consulta.
- Área de relatórios.
- Layout adaptado para desktop, tablet e celular.
- Interações básicas em JavaScript para navegação, busca, filtro, exclusão demonstrativa e mensagens de sucesso.

## Observação

Este commit é uma interface demonstrativa. A persistência dos dados e a integração com o backend existente devem ser conectadas posteriormente aos formulários e ações correspondentes.
